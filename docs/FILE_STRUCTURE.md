# File structure

Directory map of the repository and where files belong, including generated assets.

## Top-level layout
- [AGENTS.md](../AGENTS.md): repo-specific guidance for agents and workflows.
- [README.md](../README.md): project overview, citation, and doc links.
- `LICENSE`: license terms for code and documentation.
- [VERSION](../VERSION): current release version string.
- `bin`: compiled executables (generated by builds).
- `devel`: developer utilities like
  [commit_changelog.py](../devel/commit_changelog.py).
- `dist_clean.sh`: removes build artifacts before packaging.
- `docs`: project documentation.
- `publications`: published papers and PDFs.
- `python`: Python utilities and helper modules.
- `src`: C++17 sources for all command-line tools.
- `test`: legacy cached artifacts (currently
  `volume_results`).
- `tests`: regression harnesses, fixtures, and helper scripts.
- `xyzr`: converter scripts and atom-type data.

## Key subtrees
- `lib`: shared C++ helpers used across executables.
- `pyami`: Python MRC utilities used by scripts.
- `tests`: shell scripts, Python harnesses, and YAML scenarios.
- [atmtypenumbers](../xyzr/atmtypenumbers): atom-type data for converters.

## Generated artifacts
- `bin`: executable outputs from [Makefile](../src/Makefile).
- `src`: object files like `*.o` created during builds.
- `pdb_to_xyzr_results`: cached downloads,
  XYZR outputs, and MD5s from converter tests.
- `volume_results`: volume outputs and test
  artifacts from [test_suite.py](../tests/test_suite.py).
- `tests`: downloaded `*.pdb`, `*.pdb.gz`, and `*.xyzr` files from
  shell tests.
- `volume_results`: legacy cached outputs.

## Documentation map
- [AUTHORS.md](AUTHORS.md): maintainer and contributor credits.
- [CHANGELOG.md](CHANGELOG.md): chronological record of changes.
- [CODE_ARCHITECTURE.md](CODE_ARCHITECTURE.md): system design and
  data flow.
- [FILE_STRUCTURE.md](FILE_STRUCTURE.md): directory map and generated
  assets.
- [INSTALL.md](INSTALL.md): setup steps and build requirements.
- [MARKDOWN_STYLE.md](MARKDOWN_STYLE.md): documentation formatting
  rules.
- [PYTHON_STYLE.md](PYTHON_STYLE.md): Python conventions for the repo.
- [QUICKSTART.md](QUICKSTART.md): end-to-end usage walkthrough.
- [RELEASE_HISTORY.md](RELEASE_HISTORY.md): released versions and
  highlights.
- [REPO_STYLE.md](REPO_STYLE.md): repo organization and naming
  conventions.
- [TODO.md](TODO.md): backlog items and legacy work notes.
- [UTILS.md](UTILS.md): reference for shared C++ helpers.

## Where to add new work
- New C++ tools: add entry points in `src` and targets in
  [Makefile](../src/Makefile).
- Shared C++ helpers: extend `lib`.
- Converters and filters: use `src` for native code or `xyzr`
  for scripting.
- Python utilities: place scripts in `python`.
- Tests: add harnesses and fixtures in `tests`.
- Docs: add SCREAMING_SNAKE_CASE markdown files in `docs`.
